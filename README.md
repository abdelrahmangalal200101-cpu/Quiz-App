# 🎮 Quiz Game

An interactive **Quiz Game** built with **JavaScript, HTML, and CSS**.
The game fetches questions from the Open Trivia API and provides a smooth quiz experience with a timer, sound effects, and a leaderboard system.

---

## 🌐 Live Demo

🎮 Play the game online:

👉 https://abdelrahmangalal200101-cpu.github.io/Quiz-App/

---

## ✨ Features

* 🧠 Dynamic quiz questions from API
* ⏱ Countdown timer for each question
* 🔊 Sound effects using **Web Audio API**
* 🎯 Score tracking
* 🏆 High score leaderboard (stored in LocalStorage)
* 📊 Progress bar for quiz completion
* 🎮 Keyboard support (1–4 keys to answer)
* 💫 Smooth question transitions

---

## 🛠 Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript (ES6)**
* **Web Audio API**
* **Open Trivia Database API**

---

## 🚀 How to Run the Project

1. Clone the repository

```
https://github.com/abdelrahmangalal200101-cpu/Quiz-App
```

2. Open the project folder

3. Run `index.html` in your browser

---

## 🎮 How to Play

1. Enter your name
2. Select category and difficulty
3. Choose number of questions
4. Answer before the timer runs out

---

## 🔊 Sound System

The game uses **Web Audio API** to generate sounds dynamically:

* Correct Answer
* Wrong Answer
* Time Up
* Game Finished

No external audio files required.

---

## 🏆 High Scores

High scores are saved locally using **LocalStorage** and the top 10 scores are displayed in the leaderboard.
